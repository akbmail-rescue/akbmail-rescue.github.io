# Android(Pixel など)で自動スクロール録画する

パソコンとスマホを USB でつなぎ、「画面録画 → ゆっくり上にドラッグ → 少し待つ」を自動でくり返して、
AKB48 Mail のメールを次々にめくりながら録画します。手で操作する必要はありません。
動画はパソコンの `recordings` フォルダに保存されるので、それをレスキューツールに投入してください。

## 準備(最初の 1 回だけ)

1. **スマホ側**: 「設定 → デバイス情報 → ビルド番号」を 7 回タップ → 「設定 → システム → 開発者向けオプション」で **USB デバッグ** をオン
2. **パソコン側**: Google 公式の「SDK Platform-Tools」をダウンロードして展開(adb というプログラムが入っています)
   https://developer.android.com/tools/releases/platform-tools
   展開したフォルダに、この `autoscroll.ps1` をコピーしておくと簡単です
3. USB でつなぎ、スマホに出る「USB デバッグを許可しますか?」で **許可**

## 使い方

1. スマホで AKB48 Mail を開き、**最初に保存したいメールを開いた状態**にする(画面はオンのまま、自動ロックは長めに)
2. パソコンで PowerShell を開き、`autoscroll.ps1` のあるフォルダで:
   ```
   powershell -ExecutionPolicy Bypass -File .\autoscroll.ps1 -Minutes 10
   ```
   (Mac / Linux は `./autoscroll.sh 10`)
3. 5 秒後に録画とスクロールが始まります。放置してかまいません。指定した分数で自動的に止まり、動画が `recordings` に保存されます
4. 途中で止めたいときは **Ctrl+C**(それまでの動画は保存されます)
5. 保存された動画(3 分ごとに分かれています)を、まとめてレスキューツールに投入

## 調整のめやす

- 文字が読める速さでスクロールできているか、最初は 2〜3 分で試してください
- ページが切り替わったあとの待ちが短いと、本文が読み込まれる前に次へ進んでしまいます。`-WaitSeconds 3` のように増やせます
- 1 回に進む量を減らしたいときは `-DragRatio 0.35`

## うまくいかないとき

- **動画が真っ黒**: アプリが画面録画を禁止している状態です(この場合は Android では録画できません。iPhone で試してください)
- **スクロールしない**: スマホの画面が消えている/ロックされている、または「USB デバッグ」の許可ダイアログが出たままの可能性があります
- **スマホが見つかりません**: ケーブル(データ転送対応か)と、パソコン側の adb の場所(`adb` にパスが通っているか)を確認

## 注意

- ご自身の端末・ご自身のアカウントで、私的な保存のためにお使いください
- このスクリプトはパソコンとスマホの間だけで動き、インターネットには何も送りません
